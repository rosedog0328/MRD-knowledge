  • 偏差校正（HMMcopy R package）：兩次 LOESS 迴歸擬合 —— ① bin 的 GC-fraction vs read counts ② mappability uniqueness score vs read counts。僅套用於 autosome → 產出校正後 read counts r_t
  • 性別判定：依 chrY 未校正 read 比例 >0.001 且 chrX 校正後 log ratio 中位數 <−0.5 判為男性；若為男性則 chrX 的 bin 重新縮放
  • 參考集正規化（關鍵步驟）：對 27 位健康捐贈者的 ULP-WGS 逐 bin 取中位數得 h_1:T，再計算 log2 copy ratio l_t = log2(r_t / h_t)。目的是校正建庫、定序平台、cfDNA 專屬假影造成的系統性偏差
隱藏馬可夫模型（HMM）同時預測 CNA 片段與估計 tumor fraction
  • HMM + Bayesian 框架，以 EM 演算法推論
  • Emission model：log copy ratio l_1:T 用 Student's t 分布建模（參數 μ_g、λ_g、ν_g 為 copy number state g 下的均值、精度、自由度）—— 用 t 分布而非高斯以增強對 outlier 的穩健性

TF 0.03 為偵測腫瘤存在的下限；TF 0.10 為值得做 WES 的門檻
  • TF ≥ 0.10：作為『值得做標準深度 WES』的篩選門檻
  • TF 0.03（3%）：偵測腫瘤存在的下限，條件為使用 arm-level（>100 Mb）事件，最少只需一個 copy gain 加一個 copy loss
  • 以此 0.03 門檻：sensitivity 0.95 [0.94–0.96]、healthy donor 的 specificity 0.91 [0.71–0.99]

與配對腫瘤切片的一致性 + in silico 混合的敏感度/特異度
  • TF 估計準確度：與期望值的中位偏差 ≤ 0.014（0.1× 覆蓋下）
  • SCNA 偵測在 0.1× 覆蓋下即可行
  • cfDNA 與配對轉移灶腫瘤的 SCNA 高度一致（以 TITAN 的 25× WGS 結果為 ground truth，1 Mb bin 的 Spearman 相關）

本模組術語

CAPP-Seq（CAPP-Seq）
Stanford 2014 年的方法（Nat Med），整個 patient-specific panel 家族的共同祖先。用演算法設計 selector 使每位病人都被覆蓋到多個突變。LLOD 約 0.02%。⚠️ stage I 敏感度僅 50% —— 這個限制催生了後續十年的方法演進。
INVAR（INVAR）
劍橋 Rosenfeld lab 2020 年的方法（Sci Transl Med）。與 MRDetect 同期同目標但走純統計路線不用 ML：四層誤差抑制疊加（背景降 131×），以 likelihood ratio 判定，並用其他病人的樣本當陰性對照定門檻。有開源碼（INVAR2）。
MRDetect（MRDetect（第一代））
Landau lab 2020 年的方法（Nat Med），本專案的基準。核心是「廣度取代深度」：35X WGS + 全基因體數千個 SNV 累加，用線性 SVM 對單條 read 去噪（5 特徵）。LLOD 約 1e-5。⚠️ 程式碼未開源。
RCA（滾環擴增）
把 DNA 環化後沿環複製，產生含同一模板多份串聯拷貝的長分子（concatemer）。因此共識可以在單一 read 之內完成，不需要多條 read 或正反股配對。AccuScan 與 NanoRCS 皆採此法。
UMI（唯一分子標識）
建庫時接在每個原始分子上的隨機序列標籤。同一標籤的多條 read 來自同一分子，可據此取共識、消除 PCR 與定序錯誤。ONT 標準流程無此標籤。
Z-score（標準分數）
把偵測分數對陰性對照世代的分布標準化：Z = (det_rate − μ)/σ。⚠️ 本專案已降級為選項之一（2026-08-08）—— 常態假設未經檢定，且會把稀缺的陰性樣本綁去估參數。
background polishing（背景拋光）
iDES 提出的純計算去噪法：用陰性對照世代為每個位置、每種取代類型各建一個背景分布（非零 AF <5 個用 Gaussian，否則擬合 Weibull，另存零值比例），新樣本的候選變異若與該分布無法區分就移除。
blacklist（黑名單）
從 compendium 中剔除的問題位點清單。判定方式各異：MRDetect 用「≥2 個 control 出現」，INVAR 用「>10% 對照樣本出現或平均背景 >1% MAF」（排除 0.5% 位點）。⚠️ 本專案在 ONT 上用 ≥2 準則會砍掉 5% 位點。
compendium（變異圖譜）
病人（或細胞株）專屬的體細胞變異位點集合，是 tumor-informed 偵測要追蹤的目標。規模從數百（panel）到數萬（WGS）不等。本專案現行版本為 35,603 個位點。
concatemer（串聯體）
RCA 產生的長分子，內含同一原始模板的多份首尾相連拷貝。ONT 的長讀長在此有結構優勢 —— read 越長，一條 read 內能容納的拷貝越多，共識越可靠（NanoRCS 中位 6 個 subread）。
detection rate（偵測率）
本專案的定義（2026-08-09 定案）：帶到突變（ALT）的 read 數 ÷ 在 compendium 位點上檢查過的 read 數。⚠️ 論文的分子是被偵測到的位點數 M，低 TF 下兩者相同，高 TF 或有 germline 汙染時會分岔。
ichorCNA（ichorCNA）
Broad Institute 2017 年的工具（Nat Commun）。從 0.1× 超低深度 WGS 估 tumor fraction，不需事先知道腫瘤變異。用 HMM 同時預測 CNA 片段與估 TF。MRDetect 三代都在用它。 ⚠️ 偵測下限 TF 3%，遠高於 MRD 目標區間。
informative reads（有效讀取）
實際覆蓋到 compendium 位點、因而能提供資訊的 read 數。INVAR 用它作為分母，並據此為每個樣本各自估計偵測極限，而非全體共用一條線。
likelihood ratio（概似比）
INVAR 的判定量：比較「有 ctDNA」與「無 ctDNA」兩個假設下觀測資料的相對概似。用它取代「至少 N 個突變分子」的計數門檻。
outlier suppression（離群抑制）
INVAR 的關鍵步驟：低 TF 下訊號應隨機散布在各位點、多數位點為零。對此分布找 outlier 並剔除不一致的單點訊號 → control 訊號降約 3 倍，病人訊號保留 96.1%。不依賴任何平台特性。
read-centric（以 read 為單位）
與 locus-centric 相對：一次判斷的對象是一條 read，問「這一條 read 帶的突變是真的還是讀錯的」，證據來自這條 read 自身的性質（鹼基品質、比對品質、突變在 read 上的位置）。之所以必須這樣改，是因為 TF 遠小於 1／深度時每個位點最多只期待一條支持 read，使支持數門檻歸零、且位點層的 VAF 對每個被偵測到的位點都相同而失去鑑別力。
specificity（特異度）
陰性樣本被正確判為陰性的比例：TN/(TN+FP)。因為只由陰性樣本算出，不受陽性/陰性樣本組成比例影響，是跨研究比較的主指標（Precision 與 F1 則會被 prevalence 綁架）。
tumor fraction（腫瘤分數）
樣本中源自腫瘤的 DNA 佔全部 DNA 的比例。MRD 情境常低至 10⁻⁵ 甚至 10⁻⁶。本專案因使用純細胞株（purity≈1），混合時的 tumor read 比例即等同 TF。
