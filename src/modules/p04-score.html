為什麼重要

前一步（p03）處理的是單一觀測的可信度： 這一條 read 是真的還是讀錯的。

但一條 read 說明不了什麼。真正的判定要靠累加 —— 把幾萬個位點各自的微弱觀測，合成一個「這份檢體有多像含有腫瘤」的數字。 這就是第四步。

11 篇論文用了八種不同的統計方法做這件事。 它們的差別不只是「公式不同」， 而是輸出的東西根本不是同一種 —— 有的給標準差、有的給機率、 有的直接給 [[TF]] 估計值。這一頁先講清楚這件事， 再逐一說明每一種把什麼當證據。

先分清楚：輸出有四種

八種方法都在做同一件事，但合出來的「數」代表什麼，分成四類。 搞混會直接導致誤讀 —— 例如把一個概似值當成標準差來解釋。

{{svg:score-output-types | 八種聚合方法依輸出性質分成四類。四類的輸出不是同一種東西，不能直接比大小。}}
輸出的種類它在說什麼誰用需要陰性樣本世代？
一 · 標準化分數比正常人高幾個標準差 [[MRDetect]]、[[MRD-EDGE]]是（估 μ、σ）
二 · 機率／概似若真的沒有腫瘤，看到這筆資料有多不可能 [[iDES]]、[[PhasED-seq]]、[[AccuScan]]、[[INVAR]]否
三 · 直接估 [[TF]]哪個腫瘤分數最能解釋觀測 [[NanoRCS]]、[[ichorCNA]]視方法而定
四 · 學出來的機率模型認為含腫瘤的可能性（0–1） [[Lung-CLiP]]是（訓練集）

這個分類最實用的地方在最後一欄：只有第一類（與部分第三、四類）需要陰性樣本世代。 陰性樣本是稀缺資源（詳見 p05）， 因此這一欄往往才是實務上的第一個判準。

八種做法

① [[detection rate|偵測率]] → [[Z-score]]

把什麼當證據：帶到突變的 read 佔全部檢查過的 read 的比例。

最直觀的一種。先算出這份檢體的[[detection rate|偵測率]]， 再問「這個比例比陰性樣本的平均高出幾個標準差」。

{{eq}} Z = \frac{\text{det rate} − μ}{σ} {{note}} {{m: μ}}、{{m: σ}} 來自陰性樣本世代 —— 把同一份病人的變異清單套到那些樣本上算出的分數分布。 {{/eq}}

[[MRDetect]] 另有一個二項模型可從偵測數反推 [[TF]]：

{{eq}} M = N·(1 − (1 − TF)^{cov}) + μ·R {{note}} {{m: M}} 為偵測到的 SNV 數、{{m: N}} 為清單上的位點數、 {{m: cov}} 為局部覆蓋、{{m: R}} 為檢查過的 read 數。 右邊第二項 {{m: μ·R}} 就是預期的背景貢獻。 {{/eq}}

代價：{{m: μ}} 與 {{m: σ}} 必須從陰性樣本估。 [[MRDetect]] 用了 30 個對照血漿。 這批樣本一旦拿去估參數，就不能再用來算[[specificity|特異度]]。

② Poisson／幾何 偵測機率模型

把什麼當證據：不算分數 —— 直接問「以這個位點數與深度，能測到的機率是多少」。

這是八種裡最簡潔的。假設每個位點偵測到 ctDNA 分子的次數服從 Poisson， {{m: k}} 個獨立位點至少命中一個的機率即為：

{{eq}} p = 1 − e^{−n·d·k} {{note}} {{m: n}} 為基因組當量數、{{m: d}} 為偵測極限、{{m: k}} 為追蹤位點數。 這正是 p01 建立的那條式子。 {{/eq}}

它的威力在於三個參數皆可反解。 [[iDES]] 用它反推 read support 門檻；也可以反過來給定位點數與目標偵測率， 反推所需的錯誤率。[[PhasED-seq]] 用的是同一原理的二項式抽樣版本。

代價：模型較粗，未區分不同位點的背景差異 —— 它假設所有位點一樣吵，但實測上最吵與最靜的位點可以差兩個數量級。

③ 依 variant type 分層的二項式對數概似

把什麼當證據：每個位點是一次二項抽樣；把各位點的對數概似加總。

[[AccuScan]] 把每個變異的觀測看成一個二項隨機變數，成功機率為

{{eq}} p_v = VAF + e_v {{note}} {{m: e_v}} 是該 variant type 的錯誤率（C→T、C→A… 各自不同）。 把各 type 的獨立二項對數概似加總，即得樣本層分數。 {{/eq}}

關鍵設計在 {{m: e_v}} 的來源：背景錯誤模型由該血漿樣本自己量測， 不是來自對照世代 —— 對隨機選取的約 200 Mb 位置就地估計。 這是它與 ① 最大的分歧。

另有一條配套規則：低腫瘤負荷時，排除支持分子數 >1 的位點。 理由與 p03 的[[outlier suppression|離群抑制]]相同 —— 低 [[cVAF]] 下真 somatic 變異幾乎都只出現在單一分子上。 高負荷樣本（cVAF > 15%）則不套用此規則。

④ [[likelihood ratio|廣義概似比]]（GLRT）

把什麼當證據：讓「含 ctDNA」與「不含」兩個假設各自去解釋同一筆資料，看誰解釋得比較好。

{{svg:likelihood-ratio | INVAR 廣義概似比的直覺。基準不是別人的樣本長什麼樣，而是同一筆資料在虛無假設下的概似。}}

這是八種裡機制最完整、且有開源實作可直接對照的一種。 論文僅稱「INVAR likelihood ratio」，以下取自 INVAR2 原始碼 （R/shared/detectionFunctions.R）。

先寫出單一位點觀測到 mutant read 的機率

令 {{m: AF}} 為該位點在腫瘤中的 [[VAF]]、 {{m: e}} 為背景錯誤率、{{m: p}} 為樣本的 ctDNA 水準：

{{eq}} q = AF·(1−e)·p + (1−AF)·e·p + e·(1−p) {{note}} 三項分別對應「真訊號被正確讀出」「真訊號被讀錯」「野生型被讀錯」—— 把所有能產生一條 mutant read 的途徑都算進去。 {{/eq}}

再把所有位點的對數概似加起來

{{eq}} \log L = \frac{1}{n} \sum ( \text{lchoose}(R, M) + M · \log q + (R − M) · \log (1 − q) ) {{note}} {{m: M}} 為該位點的 mutant read 數、{{m: R}} 為深度、{{m: n}} 為位點數。 原始碼中此式除以 {{m: \text{length}(R)}}，即對位點數取平均。 {{/eq}}

ctDNA 水準 p 以 EM 演算法估計

{{cli}} # estimate_p_EM(M, R, AF, e, initial_p = 0.01, iterations = 200) g = AF*(1-e) + (1-AF)*e for (i in 1:200) { # E 步 Z_0 <- (1-g)*p / ((1-g)*p + (1-e)*(1-p)) Z_1 <- g*p / (g*p + e*(1-p)) # M 步 p <- sum(M*Z_1 + (R-M)*Z_0) / sum(R) } {{/cli}}

最後取兩個假設的差

{{eq}} LR = \log L(p = \hat{p}_{MLE}) − \log L(p = 0) {{note}} 虛無假設為 {{m: p = 0}}（樣本不含 ctDNA）。 {{m: LR}} 越大，「含 ctDNA」的解釋越優於「不含」。 {{/eq}}

為什麼它不需要陰性樣本世代： 它的基準不是「別人的樣本長什麼樣」， 而是同一筆資料在虛無假設下的概似 —— 基準完全由這份樣本自己提供。

原始碼有兩個版本，選錯會用到不適用的假設

INVAR2 另有 *_with_RL 版本，把片段長度分布納入概似式 （腫瘤來源的 cfDNA 片段較短，可作為額外證據）。

該版本假設樣本是 [[cfDNA]]。 若樣本並非 cfDNA（例如細胞株的基因體 DNA），片段長度分布不具代表性， 應使用無片段長度的版本。

⑤ [[Monte Carlo]] 模擬

把什麼當證據：反過來做 —— 模擬各種 TF 下會看到什麼，找出最像實際觀測的那個 TF。

[[NanoRCS]] 的做法：輸入三個量 —— ① 觀測到的 tumor-informed SNV 數、 ② 每個 SNV 在腫瘤中的 [[VAF]]、 ③ 定序錯誤率 —— 然後大量模擬，推估最可能的 [[TF]]。

好處是輸出本身就有物理意義（不是抽象分數，而是一個 TF 估計值）， 且不需要對背景分布做參數假設。代價是計算量大。

⑥ [[HMM]] + Student's t + [[EM algorithm|EM]]

把什麼當證據：不看點突變 —— 看沿著染色體走時，深度在哪裡發生系統性偏移。

[[ichorCNA]] 處理的是 CNA 而非 SNV，因此聚合方式完全不同。 它把基因體切成 1 Mb 的 bin，用隱藏馬可夫模型沿染色體推論每一段的拷貝數狀態， 同時估出 [[TF]]。

兩個值得記的設計選擇：

  • 觀測值用 Student's t 分布而非高斯 —— t 分布的尾部較厚，對離群值更穩健。
  • 均值採三成分混合，同時容納 normal fraction、腫瘤倍體與 subclonal fraction； clonal 時退化為二成分。

⑦ 樣本層級 ML 分類器

把什麼當證據：不預設用哪個統計量 —— 把多種特徵一起餵給模型，讓它學。

[[Lung-CLiP]] 是三層架構的最後一層： 把第一層的 SNV model 輸出（每個突變是腫瘤來源的機率） 與第二層的全基因體 CNA 判讀整合， 輸出「這份血液樣本含有肺癌來源 cfDNA 的可能性」。

這是最貼近「MRD 是分類問題」這個框架的一種做法 —— 一個檢體就是一列資料，輸出直接是機率。 代價是需要訓練資料，而且訓練與測試必須依病人切分。

⑧ [[Stouffer's method|Stouffer 合併]]

把什麼當證據：已經有好幾個獨立的分數了 —— 怎麼合成一個。

嚴格說這不是一種聚合方法，而是聚合之後的再聚合。 [[MRD-EDGE]] 的 CNV 訊號來自三個獨立來源（read-depth、BAF／cnLOH、片段特徵）， 各自得到一個 Z，再合併：

{{eq}} Z = ( \sum Z_i ) / \text{根號 k} {{note}} {{m: k}} 為來源數。分母取 {{m: k}} 的平方根， 是因為 {{m: k}} 個獨立標準常態變數之和的標準差正好等於 {{m: k}} 的平方根。 {{/eq}}

前提是各來源彼此獨立 —— 若三個來源其實高度相關，合併會高估顯著性。

關鍵分歧只有一個

八種方法的共同點是全部都在把 N 個弱觀測合成一個數， 差別只在使用哪個機率模型。真正影響實務選擇的分歧只有一條：

只有 ① 這一系需要對照世代來估 {{m: μ}} 與 {{m: σ}}。 其餘做法或用統計模型直接推導（②④）， 或由樣本自身量測背景（③），或用模擬（⑤）—— 不消耗稀缺的陰性樣本。

為什麼這件事這麼重要，見下一頁 p05： 陰性樣本同時是「定門檻用」與「算特異度用」的唯一來源， 一份樣本只能有一個角色。
