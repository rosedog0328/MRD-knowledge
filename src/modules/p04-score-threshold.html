為什麼重要

前一步處理的是單一觀測的可信度，這一步處理的是如何把成千上萬個 弱觀測合成一個判定。

這兩步對本專案特別關鍵，原因是[[control cohort|陰性樣本]]稀缺： 本專案只有 5 個獨立陰性個體， 而文獻中的方法動輒需要 12 至 30 個。 本頁的核心問題是：有沒有不需要陰性樣本世代的路徑。

答案是有，而且有兩條，各有一線期刊的先例。

共同點與關鍵分歧

共同點：八種做法全部都在做同一件事 —— 把 N 個弱觀測合成一個數。差別只在使用哪個機率模型。

關鍵分歧：只有 [[MRDetect]] 世系需要 [[control cohort|對照世代]]來估 [[Z-score]] 的 μ 與 σ。 其餘做法或用統計模型直接推導，或由樣本自身量測背景 —— 不消耗稀缺的陰性樣本。

本專案已否決 Z-score 路線

本專案於 2026-08-08 將 [[Z-score]] 降級為選項之一，理由有三： 常態假設從未檢定；它把稀缺的陰性樣本綁去估參數， 導致測試集沒有乾淨的陰性樣本可算 [[specificity|特異度]]； 且它只用到一個純量，丟棄其他可用的檢體層級資訊。

因此本頁其餘七種做法都是實際的候選，而非僅供參考。

兩個最完整的替代方案

其一：iDES 的偵測機率模型

最簡潔的一種。三個參數皆為本專案已知或可量測的量。

{{eq}} p = 1 − e^{−n·d·k} {{note}} {{m: n}} 為基因組當量數、{{m: d}} 為偵測極限、{{m: k}} 為追蹤位點數。 可解任一參數 —— 例如給定 {{m: k = 35{,}603}} 與目標 {{m: p}}，反推所需的 {{m: d}}。 {{/eq}}

[[iDES]] 以此建立 read support 門檻， 不需要任何陰性樣本；其代價是模型較粗， 未區分不同位點的背景差異。

其二：INVAR 的廣義概似比檢定

較完整的一種，且有開源實作可直接對照。 論文僅稱「INVAR likelihood ratio」， 以下取自 INVAR2 原始碼（R/shared/detectionFunctions.R）。

對數概似函數：令 {{m: M}} 為某位點的 mutant read 數、{{m: R}} 為深度、 {{m: AF}} 為該位點在腫瘤中的 [[VAF]]、{{m: e}} 為背景錯誤率、{{m: p}} 為樣本的 ctDNA 水準，

{{eq}} q = AF·(1−e)·p + (1−AF)·e·p + e·(1−p) {{note}} {{m: q}} 是在給定 {{m: p}} 下，該位點觀測到 mutant read 的機率 —— 三項分別對應「真訊號被正確讀出」「真訊號被讀錯」「野生型被讀錯」。 {{/eq}} {{eq}} \log L = \frac{1}{n} \sum ( \text{lchoose}(R, M) + M · \log q + (R − M) · \log (1 − q) ) {{note}} {{m: n}} 為位點數；{{m: \text{lchoose}(R,M)}} 即 R 取 M 的二項式係數取對數。 原始碼中此式除以 {{m: \text{length}(R)}}，即對位點數取平均。 {{/eq}}

樣本的 ctDNA 水準 {{m: p}} 以 EM 演算法估計：

{{cli}} # estimate_p_EM(M, R, AF, e, initial_p = 0.01, iterations = 200) g = AF*(1-e) + (1-AF)*e for (i in 1:200) { # E 步 Z_0 <- (1-g)*p / ((1-g)*p + (1-e)*(1-p)) Z_1 <- g*p / (g*p + e*(1-p)) # M 步 p <- sum(M*Z_1 + (R-M)*Z_0) / sum(R) } {{/cli}}

最後取虛無假設與最大概似估計之差：

{{eq}} LR = \log L(p = \hat{p}_{MLE}) − \log L(p = 0) {{note}} 虛無假設為 {{m: p = 0}}（樣本不含 ctDNA）。 {{m: LR}} 越大，「含 ctDNA」的解釋越優於「不含」。 {{/eq}}

為什麼這個方案對本專案特別合適

  • 不需要對照世代估 μ、σ —— 繞開陰性樣本稀缺的困境。
  • 輸入只需要每個位點的四個量：{{m: M}}、{{m: R}}、{{m: AF}}、{{m: e}}，全部是本專案已有或可算的。
  • 有開源實作可比對，不必從論文文字重建。
  • ⚠️ 原始碼另有 *_with_RL 版本，把片段長度分布納入概似式 —— 該版本對細胞株 gDNA 不適用，應使用無片段長度的版本。

陰性樣本稀缺的兩條解法

本專案僅有 5 個獨立陰性個體（4 個 UCSC normal 加 held-out 的 COLO829BL）， 不足以支撐前四種方式。但最後兩種不受此限：

解法作法先例
用其他個體的樣本當陰性對照 把 A 的變異清單套到 B 的樣本上 —— 任兩個個體的 somatic 變異幾乎不重疊，故 B 自然是 A 的陰性對照 [[INVAR]]（Sci Transl Med）：要求 [[specificity|特異度]] ≥90%，實測中位 95%
[[MRD-EDGE]] 亦採此法
完全不用陰性樣本 設定 [[nominal specificity|名目特異度]]（如 99%），由背景錯誤模型直接反推門檻 [[AccuScan]]：背景由樣本自身量測；實測特異度 ≥99%

本專案現行的 [[cross-sample normal|跨個體正常樣本]]即是第一條解法的實作， 與 INVAR 的 [[cross-patient control]] 概念相同。

{{guard:10 | INVAR 作者自承：逐 cohort 定門檻不是長久之計}}

INVAR 在 Discussion 中寫道，其效能是以 「ROC analysis across individual cohorts」評估的， 但「when applied at scale, it would be desirable to set a fixed specificity threshold」。

換言之，作者自己認為逐世代重新畫 ROC 定門檻只是權宜之計， 規模化時應改為固定特異度門檻。

這正對應本專案的要求：門檻只能用訓練／驗證樣本決定， 決定後凍結並寫入報告，再跑測試集。

{{/guard}} {{guard:11 | 提供過任何擬合量的樣本，不得再充當測試集的陰性樣本}}

凡是從資料學出來的量都算擬合，不只是模型權重 —— 還包括判定門檻、標準化參數、以及（若沿用 Z-score）μ 與 σ。

用來提供這些量的陰性樣本，若又拿去算 [[specificity|特異度]]， 等於用訓練資料證明自己不會誤判。

這條紀律與論文無關，不因換掉 Z-score 而消失。 但哪些樣本拿去擬合是自由的設計選擇 —— 若改用不需陰性樣本的門檻（上表最後兩種）， 原本綁在估參數上的樣本即可釋出，改派為測試集的陰性樣本。

{{/guard}}
